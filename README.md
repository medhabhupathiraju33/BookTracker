# BookTracker
 A simple command-line tool that helps readers track organize their reading lists and manage their personal libraries.

## The Problem + Goal
 It can get tricky to manage a bunch of different lists of books (to be read, currently reading, finished). This solves the problem because it provides a convenient interface to safely store reading data.

## MVP Scope - Version 1.0
- Main Menu: A continuous loop that provides an easy way to navigate the options.
- Add Books: Ask user for title and author of the book they want to add to a list
- View Lists: Display the different lists of books directly in the terminal.
- Saving Data: Save the reading data locally to json file each time it's updated.
[System Diagram] (docs/System Diagram.png)

## Future Plans
- Be able to move books between the different lists
- Random Book: Choose a random book to read from the list of books to be read
- Rating System: Rate finished books.
- Progress: Tracking the progress of the book currently being read and when it's finished.

## Tech Stack
- Language: Python 3
- Built-In Library: Json, Random, Datetime
